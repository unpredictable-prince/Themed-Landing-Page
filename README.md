## 🔬 Core Architecture & Features

### 1. Cybernetic HUD Aesthetics & Design System
- **Palette**: Matte obsidian dark scheme (`#05070a`, `#080c14`), laser crimson accents (`#ff0055`), toxic cyan glow (`#00f0ff`), and holographic amber highlights (`#ffaa00`).
- **HUD Micro-Elements**: Mechanical angled clip-paths (`polygon()`), corner target brackets, glowing scanning laser sweep, and telemetry badges.
- **Biometric 2D HTML5 Canvas**: Real-time particle connection matrix reacting dynamically to cursor velocity and proximity magnetism.
- **Custom Cyber Cursor**: Dual-element crosshair target reticle with trailing lerp physics and interactive hover states.

### 2. Interactive 3D Holographic Chassis Lab (`#hologram`)
- Canvas-driven 3D wireframe mesh with real-time perspective projection.
- Interactive mouse click & drag 3D rotation with dynamic angle readout.
- Telemetry layer filters: **Full Matrix**, **⚡ Neural Lattice**, **🛡️ Titanium Cage**, and **🔋 Fusion Core**.

### 3. Biometric Diagnostics & Configurator (`#diagnostics`)
- Live SVG anatomical scan with 6 dynamic glowing hotspot indicators.
- Real-time recalculation of **Combat Rating (%)**, **Power Draw (kW)**, and **Unit Cost (₭)**.
- One-click build presets:
  - ⚔️ *Assault Build*
  - 👤 *Ghost Stealth*
  - ⚡ *100% Max Overclock*
  - 🔄 *Reset Core*

### 4. Augmentation Catalog with Instant Search (`#catalog`)
- Full module breakdown for all 6 cybernetic systems:
  - **Neural Link v4** (Class Omega)
  - **Titan Chassis Arm** (Class Titan)
  - **Cyber-Optic Oculus** (Class Recon)
  - **Sub-Dermal Armor Mesh** (Class Bulwark)
  - **Apex Reflex Synapse** (Class Velocity)
  - **Phantom Cloaking Core** (Class Stealth)
- Real-time search bar and category filter pills (`ALL`, `OMEGA`, `TITAN`, `RECON`, `BULWARK`, `VELOCITY`, `STEALTH`).
- Direct *Equip to Chassis* toggle syncing with the configurator.

### 5. Overclocking Benchmark Stress Lab (`#benchmark`)
- Real-time waveform oscilloscope canvas animation.
- Interactive 10-second **Neural Overclock Stress Test** with frequency sweeps (up to 14.85 GHz), thermal overload gauges, and live telemetry log stream.
- **EMP Kinetic Shield Test** with shockwave dissipation.

### 6. Declassified FAQ & Terminal CLI Shell (`#faq`)
- Classified telemetry accordion log.
- In-browser interactive CLI emulator with command execution (`help`, `scan`, `overclock`, `modules`, `status`, `dossier`, `whoami`, `clear`) and quick-run chips.

### 7. Surgical Requisition Dossier & Digital Signature Pad
- Order summary calculating equipped implants.
- Interactive digital signature canvas pad (draw signature with mouse or touch).
- Confetti particle burst and cryptographic confirmation log.

### 8. Web Audio Synthesizer & HUD Sound Controls
- Procedural sound effect generation via Web Audio API (tones, blips, overclocking ramps, modal chimes).
- Header audio toggle with animated equalizer bars.

## 🚀 Getting Started / Run Locally

Clone the repository and launch a local web server:

```bash
# Clone repository
git clone https://github.com/unpredictable-prince/Themed-Landing-Page.git

# Navigate into project directory
cd Themed-Landing-Page

# Start local server (Python 3)
python3 -m http.server 8000
```

Open your browser and navigate to:
👉 **[http://localhost:8000](http://localhost:8000)**

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5 with accessibility attributes
- **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid, Clip-path polygons, Keyframe Animations)
- **Logic & Interactions**: Modern Vanilla JavaScript (ES6+), HTML5 Canvas 2D & 3D Perspective Math, Web Audio API
- **Animation**: GSAP (GreenSock) & ScrollTrigger
- **Icons**: Lucide Icons
- **Effects**: Canvas-Confetti
